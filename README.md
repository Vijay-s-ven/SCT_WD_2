#  Stopwatch Web Application

A responsive and user-friendly stopwatch web application built using HTML, CSS, and JavaScript that allows users to accurately track time, pause, reset, and record lap intervals.

##  Features
- Start, pause, and reset stopwatch
- Record multiple lap times
- Clean and minimal user interface
- Responsive design for all screen sizes
- Pure JavaScript logic (no libraries used)

##  Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

##  Project Structure
stopwatch/
├── index.html
├── style.css
└── script.js

##  How to Run the Project
1. Download or clone the repository
2. Make sure all files are in the same folder
3. Open `index.html` in any modern web browser

##  Preview
The application displays a digital stopwatch with controls to manage time tracking and lap recordings.

##  Use Case
This project demonstrates core front-end development skills such as DOM manipulation, event handling, and UI design, making it suitable for learning and internship showcases.
